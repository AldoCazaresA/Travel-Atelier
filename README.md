# Aura Nomada | Agencia de Viajes

Landing page de una agencia boutique de viajes enfocada en experiencias premium, escapadas románticas, viajes familiares y paquetes personalizados.

## Descripción

Este proyecto es una página web estática con diseño moderno y visualmente atractivo para promocionar tours, destinos, paquetes y servicios de una agencia de viajes. La interfaz está diseñada para generar confianza, mostrar propuestas de viaje y captar solicitudes de cotización desde el mismo sitio.

La página incluye:

- Hero section con video de fondo y llamado a la acción
- Sección de destinos destacados
- Cards por tipo de experiencia o colección
- Formulario de planificación del viaje
- Formulario de contacto para enviar una solicitud por correo
- Navegación responsive
- Estilo visual premium con paleta de colores sobria y elegante

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Imágenes y videos de fuentes externas (Unsplash, Pexels)

## Estructura del proyecto

- `codex.html`: estructura principal de la página
- `styles.css`: estilos visuales del sitio
- `script.js`: interacciones de navegación y envío de formularios
- `README.md`: documentación del proyecto

## Cómo ejecutar

Puedes abrir directamente el archivo `codex.html` en tu navegador para visualizar la página.

## Funcionalidad principal

Los formularios están conectados con el cliente de correo del usuario mediante `mailto`, para que al enviar una solicitud se abra una nueva ventana de correo con el contenido del viaje ya preparado.

## Objetivo del sitio

El sitio busca posicionar la marca como una agencia de viajes premium y convertir visitas en cotizaciones, mostrando un estilo aspiracional y una experiencia visual clara para diferenciar cada tipo de viaje.
